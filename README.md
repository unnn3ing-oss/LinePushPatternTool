# Line推播套版產生器

**線上直接使用（GitHub Pages）：** https://unnn3ing-oss.github.io/LinePushPatternTool/

單一 HTML 檔案的小工具，固定「熱門話題」六宮格版型（頂部標籤列＋下方 3×2 共 6 格）。成品是**兩頁各自獨立**（預設第 1 頁含黃色標籤列、第 2 頁不含，僅頂部淡淡暗角），可分別更換每一頁每一格的照片、兩行標題文字與選填的小標籤（紅／灰底色可選），文字自動排版（字沒塞滿字框維持自然字距，太長才縮字距／字級），照片可拖曳調整位置、滾輪或滑桿縮放。預覽與下載檔案都是 1040×800，下載為高品質 JPG 並內嵌 300dpi 資訊。

跟 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool) 是同一套操作邏輯（單一 HTML、Canvas 2D 即時預覽、拖曳/貼上上傳圖片），但版型固定為六宮格、成品分兩頁，並新增照片拖曳定位、縮放、標籤與自動字距／字級的功能。

## 功能特色

- **新聞／娛樂兩種版型**：畫面最上方切換。「新聞」為上述熱門話題六宮格（1040×800）；「娛樂」為拍立得四格（1200×1200，每格照片＋黃色字條上兩行標題＋藍色標籤，第一行預設藍字、第二行黑字），下載檔案為 1040×1040、300dpi JPG（以 2 倍算圖後高品質縮小，維持清晰度）。兩種版型的資料各自保留、切換不會遺失，編輯、貼圖、快速填入（娛樂版一次填 8 格）共用。娛樂版標題字級依設計範例：基準 61px，字太長時先把字距壓緊（可到 -0.07em，讓字彼此貼近），仍放不下才縮字級，所以長句也維持接近原尺寸；標題並加 1px 同色描邊，粗細對齊範例（標籤文字不加粗）。同一列左右兩格的兩行標題與標籤高度一致。標籤為略斜的藍色撕邊膠帶造型，會依字數水平拉長。
- **拼圖**：第三個版型分頁，一張 1:1 畫布把多張照片無縫拼接。可「等分」（直向、橫向各不切～4 等分，在預覽圖上拖曳分隔線調整比例），或「自由框」（拖曳拉出矩形、移動、拉邊角改大小、磁吸貼齊、調整上下層、刪除，最多 12 框）。每框照片可拖曳、縮放、加T寶貼圖。「下載」為 1080×1080、300dpi JPG，檔名 `yyyymmdd拼圖.jpg`；「複製」會把成品放進剪貼簿，切到新聞或娛樂點選格子按 Ctrl+V 即可貼成該格照片（貼入非正方形格子時可再拖曳、縮放調整）。
- **兩頁各自獨立**：預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換編輯，兩頁各有自己的 6 格內容（照片、文字、標籤、顏色）與「頂部標籤」（顯示黃色標籤列）開關，互不影響；切頁不會遺失另一頁的資料。
- **固定版型**：頂部標籤列（可切換顯示／隱藏、可改文字，預設「熱門話題」）＋下方 3×2 共 6 格，每格可獨立設定。背景／漸層直接套用實際輸出的模板 PNG 素材，確保跟原始設計完全一致。
- **選填標籤**：每格可加一個白字小標籤（例如「關鍵竟是房東」），底色可選紅色或灰色，顯示在該格標題文字正上方、靠左對齊。
- **第二段標籤（新聞版）**：每格可再加「標籤文字 2」（獨立的紅／灰底色），預設在該格右上角；快速填入只會填第一段。兩段標籤都能在預覽圖上直接拖曳，移動範圍限制在該格內、標題文字上方，並避開上方的黃色標籤列漸層與兩排之間的黑帶（第 1、2 頁各有各的上界，數值量自模板 PNG）；靠近格子邊緣會自動吸附貼齊，不顯示輔助線。「標籤位置還原」可把兩段標籤放回預設位置。娛樂版暫無第二段標籤。
- **文字自動排版**：每格兩行標題，兩行都可分別選顏色（白／黃／紅／藍／綠／黑），預設依欄位交錯白／黃配色。文字框左右完全貼齊格子邊線：字沒塞滿時維持自然字距置中，字距拉滿到貼邊仍放不下才開始壓縮字距，字距壓到 0（再壓會讓筆畫重疊）仍放不下才縮小 1 級字級，如此重複到能放進格子為止。
- **標點符號自動轉半形**：兩行標題、標籤文字、頂部標籤文字，以及「快速填入」貼入的內容，只要含有全形標點（！？（）＂＇，。、～等）或中文彎引號，都會自動轉成半形／直引號，不用自己切換輸入法。
- **快速填入**：預設展開（點標題可收起），可直接貼上整段過審的推播新聞（「★標題」＋下一行網址，網址會自動略過）；標題碰到空格（全形、半形）或「!」「?」就自動換到第二行（驚嘆號、問號留在第一行尾），依序自動套進第 1～12 格（第 1 頁 6 格接著第 2 頁 6 格，由左至右、由上至下），不用一格一格手動輸入。標籤文字支援兩種寫法，都寫在★後方，自動偵測：緊接「標籤文字)」（開頭無括號）或「(標籤文字)」／「（標籤文字）」，會自動拆出來填入該格的標籤欄位，標籤是「國際」時自動選灰色底、其餘一律紅色底。
- **快速填入自動抓文章首圖**：★ 標題下一行的文章連結，會自動抓該文章的第一張圖（og:image，沒有就取內文第一張）放進對應格子；之後想換圖，拖進新圖或 Ctrl+V 即可，手動放的圖再按快速填入也不會被蓋掉，抓不到的格子會在狀態列列出請手動放圖。瀏覽器不能直接讀其他網站內容，所以需要一個自架的 Cloudflare Worker 代理（只允許 tvbs.com.tw，程式碼與部署步驟見 [`worker/README.md`](worker/README.md)）；網頁以 `?imageProxy=<worker網址>` 開啟一次即記住設定（也可直接寫進 `DEFAULT_IMAGE_PROXY`），未設定時快速填入只填文字。
- **複製推播連結**：新聞／娛樂在「步驟 2 畫面檢查」點預覽圖上的格子，預覽下方會出現「複製推播連結」按鈕（編輯畫面時不顯示），只複製該格的**連結**（不含標題）。連結會先清掉文章編號之後的所有參數（舊的 utm 與其他參數全部刪除，只留文章網址），再加上對應的追蹤碼；連結來自快速填入時標題下一行的網址，沒有連結的格子會提示無法複製。範例：
  - 原始連結：`https://news.tvbs.com.tw/life/4030991`
  - 加上新聞推播追蹤碼：`https://news.tvbs.com.tw/life/4030991?utm_source=LineNewsPush&utm_medium=push`
  - 加上娛樂推播追蹤碼：`https://news.tvbs.com.tw/life/4030991?utm_source=LineNewsPush&utm_medium=enewsline`
- **照片編輯**：點擊、拖曳檔案，或先點選該格再用 Ctrl+V 貼上剪貼簿圖片即可上傳；直接在預覽圖上對著照片拖曳可調整位置，滑鼠停在該格上滾動滾輪、或用「圖片縮放」滑桿可放大縮小；「重設位置」可還原置中。照片放大後可再多拖出照片自身寬高各 7% 的邊界（露出白底），方便把邊緣的人物拉向中間。單擊預覽圖上的任一格只會選取該格並在左側浮出對應的編輯面板，雙擊該格才會開啟選擇檔案視窗。
- **T寶貼圖**：先在預覽圖點選要編輯的格子，點畫面底部浮動工具列「T寶貼圖」裡的其中一個表情貼圖即可加到該格正中央，用來蓋住照片中不想露出的人物（步驟 2 會鎖定，工具列上不顯示）。貼圖可在預覽圖上直接拖曳移動、滑鼠滾輪縮放，點貼圖右上角的「✕」即可移除；貼圖只存在於該格、該頁，切頁或清除本頁不影響其他頁。
- **操作提示彈窗**：網頁右下角的彈窗（新聞版顯示快速填入、單格修正、小標籤、照片縮放留白等要點；其他版型只有說明按鈕），最下方的「詳細功能說明」按鈕會開啟完整使用說明（操作流程、拼圖、快速填入示範、輸出格式；頁首不再有使用說明按鈕）。開啟網頁時自動展開，15 秒內沒有點擊或捲動內容就會往下收起，也可按 ✕ 手動收起，收起後右下角留下圓形「!」按鈕，點一下可再次開啟。
- **浮動面板編輯（點格子才出現）**：預覽圖固定在畫面正中間，編輯面板浮在預覽圖左側、緊貼預覽圖（相隔約 18px，視窗再寬也不會離很遠），頂端與預覽圖齊高。一開始左側是「快速填入」；新聞版點預覽圖上黃色的「熱門話題」標籤列，左側會浮出「頂部標籤」面板（取消勾選隱藏標籤列後，最上方「拼圖」右側會出現「頂部標籤」按鈕可再打開）；在預覽圖上點某一格，左側就換成那一格的編輯面板（新聞、娛樂、拼圖皆同），點畫面空白處或換頁則收起。按下「快速填入」後面板會自動收起，最上方「拼圖」右側會獨立出現「快速填入」按鈕可再打開。
- **每格欄位配置**：每一行標題文字／標籤文字的輸入框上方都是一列「欄位名稱＋顏色選取」（例如「第一行標題」＋色塊），顏色選取預設收合只顯示目前顏色的色塊，點一下展開完整選色列。
- **兩步驟流程（新聞、娛樂）**：畫面最上方有進度條「① 編輯畫面 → ② 畫面檢查」。步驟 1 編輯內容（貼上快速填入、點格子改字／換圖、拖曳縮放、貼 T寶貼圖）；按底部「下一步：畫面檢查」進入步驟 2，**照片、標籤、貼圖全部鎖定**，拖曳時會跳出「照片已鎖定　返回上一步更改」提醒。步驟 2 左側逐格列出檢查結果（綠色圓圈「圖」「字」＝沒問題，紅色圓圈「!」＝缺圖片／缺標題，黃色圓圈「!」＝疑似露白；預覽圖上有問題的格子左上角也會標同樣的圓圈）：缺圖片、缺標題（沿用原本的完整度規則，會鎖住「全部下載」）以及圖片疑似露白（顯示黃色圓圈「!」，預覽圖上該格左上角也會標示；不鎖定下載，但按「下載本頁」「全部下載」時會跳提示「圖片有露白確定要下載嗎？」，可選擇仍要下載）；點預覽圖上的格子，預覽下方會出現該格的「複製推播連結」。**只有步驟 2 才有「下載本頁」「全部下載」**，要修改按底部「返回編輯」。拼圖沒有標題檢查，所以沒有進度條與步驟 2，底部直接是「下載」與「直接複製」。
- **下載**：下載按鈕在畫面底部的浮動工具列（新聞、娛樂在步驟 2）。下載檔案尺寸固定為新聞 1040×800、娛樂 1040×1040，以高品質（0.95）JPG 輸出避免小字被壓縮糊掉，並在檔案內嵌 300dpi 資訊（PNG 的 pHYs 區塊／JPG 的 JFIF 密度欄位）。檔名格式為「下載當天日期＋版型＋Line推播圖_第幾頁」，例如 `20260925新聞Line推播圖_第1頁.jpg`。按「全部下載」時，按鈕上方會先跳出確認「已確認無錯字、圖片無露白？」，選「確認下載」才會下載，「再修改」或點別處可取消。
  - 下載本頁：目前分頁畫面上所有照片＋文字的完成品（JPG）。
  - 全部下載：一次把兩頁的完成品各存一張 JPG（部分瀏覽器第一次使用會詢問是否允許網站下載多個檔案，允許即可）。

## 使用方式

1. 開啟本頁（線上版或本機伺服器，見下方「本地開發」）。
2. 在左側「快速填入」貼上成批標題內容一次套用，或用預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換、點格子手動編輯。
3. 新聞版需要的話，點預覽圖上黃色的「熱門話題」標籤列，在左側浮出的面板切換是否顯示標籤列、修改標籤文字。
4. 依序為六格上傳照片、輸入兩行標題文字（顏色選取預設收合，點欄位名稱或色塊即可展開選色）與選填標籤。
5. 在預覽圖上拖曳/滾輪調整照片位置與縮放；單擊預覽圖上的格子會在左側浮出對應編輯面板，雙擊該格則開啟選擇檔案視窗。
6. 按底部「下一步：畫面檢查」核對缺圖、缺標題、露白，確認後按「下載本頁」取得單頁成品，或「全部下載」一次拿兩張（拼圖沒有這一步，直接按底部「下載」）。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部功能所在，純 HTML + CSS + 原生 JavaScript（Canvas 2D 繪圖），無外部相依套件 |
| `TaipeiSansTCBeta-Bold.woff2` | 標題套用的字型（台北黑體 Taipei Sans TC Beta Bold）的 WOFF2 壓縮版，瀏覽器優先載入這個（比 .ttf 小約 65%，字元涵蓋範圍完全相同） |
| `TaipeiSansTCBeta-Bold.ttf` | 同一套字型的原始 TTF，僅作為不支援 WOFF2 的舊瀏覽器備援，一般瀏覽器不會下載到這個檔案 |
| `assets/template-header.png` | 含頂部黃色標籤列的模板圖層，Canva 原始匯出檔，直接套用不重繪 |
| `assets/template-plain.png` | 不含標籤列（僅頂部淡淡暗角）的模板圖層，同樣是 Canva 原始匯出檔 |
| `worker/og-image-proxy.js` | Cloudflare Worker：快速填入抓文章首圖用的小代理（需自行部署，說明見 `worker/README.md`） |
| `assets/template-ent.png` | 娛樂版拍立得四格模板（1200×1200，照片框為透明），由設計稿還原；拿到設計原檔後直接以同檔名覆蓋即可 |
| `assets/stickers/*.png` | 可疊加在照片上、用來遮擋人物的 T 寶表情貼圖（透明背景 PNG） |
| `assets/icons/*` | 網頁分頁圖示（favicon），喇叭圖案，呼應版型本身的黃色標籤列圖示 |

## 技術說明

- 純前端實作，圖片合成、文字排版（含逐字距調整）皆透過 Canvas 2D API 即時繪製；版型的漸層／標籤列是直接 `drawImage` 疊上 `assets/` 底下的原始模板 PNG，不是用程式碼重繪近似圖形。
- 無框架、無建置流程。
- 下載功能使用 `canvas.toDataURL()` 產生檔案，全程在瀏覽器端完成，不會上傳任何圖片或文字內容到伺服器。

## 本地開發

因為版型會載入 `assets/` 底下的本機 PNG 圖檔疊到 canvas 上，瀏覽器基於安全限制，**直接雙擊開啟 `index.html`（`file://`）會導致下載失敗**（跳出提示訊息，canvas 被視為跨來源而無法匯出）。本機測試請先起一個簡單的 HTTP 伺服器再開啟，例如：

```
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```

部署後的網址（GitHub Pages 等正式 http/https 環境）不受此限制，可正常下載。
