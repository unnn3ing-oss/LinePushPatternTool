# Line推播套版產生器

**線上直接使用（GitHub Pages）：** https://unnn3ing-oss.github.io/LinePushPatternTool/

單一 HTML 檔案的小工具，固定「熱門話題」六宮格版型（頂部標籤列＋下方 3×2 共 6 格）。成品是**兩頁各自獨立**（預設第 1 頁含黃色標籤列、第 2 頁不含，僅頂部淡淡暗角），可分別更換每一頁每一格的照片、兩行標題文字與選填的小標籤（紅／灰底色可選），文字自動排版（字沒塞滿字框維持自然字距，太長才縮字距／字級），照片可拖曳調整位置、滾輪或滑桿縮放。預覽畫面是 1040×800，下載檔案會以 2 倍解析度（2080×1600）匯出並內嵌 300dpi 資訊。

跟 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool) 是同一套操作邏輯（單一 HTML、Canvas 2D 即時預覽、拖曳/貼上上傳圖片），但版型固定為六宮格、成品分兩頁，並新增照片拖曳定位、縮放、標籤與自動字距／字級的功能。

## 功能特色

- **兩頁各自獨立**：預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換編輯，兩頁各有自己的 6 格內容（照片、文字、標籤、顏色）與「顯示頂部黃色標籤列」開關，互不影響；切頁不會遺失另一頁的資料。
- **固定版型**：頂部標籤列（可切換顯示／隱藏、可改文字，預設「熱門話題」）＋下方 3×2 共 6 格，每格可獨立設定。背景／漸層直接套用實際輸出的模板 PNG 素材，確保跟原始設計完全一致。
- **選填標籤**：每格可加一個白字小標籤（例如「關鍵竟是房東」），底色可選紅色或灰色，顯示在該格標題文字正上方、靠左對齊。
- **文字自動排版**：每格兩行標題，兩行都可分別選顏色（白／黃／紅／藍／綠／黑），預設依欄位交錯白／黃配色。文字框左右完全貼齊格子邊線：字沒塞滿時維持自然字距置中，字距拉滿到貼邊仍放不下才開始壓縮字距，字距壓到 0（再壓會讓筆畫重疊）仍放不下才縮小 1 級字級，如此重複到能放進格子為止。
- **標點符號自動轉半形**：兩行標題、標籤文字、頂部標籤文字，以及「快速填入」貼入的內容，只要含有全形標點（！？（）＂＇，。、～等）或中文彎引號，都會自動轉成半形／直引號，不用自己切換輸入法。
- **快速填入**：預設收合成一列標題，點擊展開後可貼上「★標題第一行 標題第二行」＋下一行網址（網址會自動略過）的成批內容，依序自動套進第 1～12 格（第 1 頁 6 格接著第 2 頁 6 格，由左至右、由上至下），不用一格一格手動輸入。標籤文字支援兩種寫法，都寫在★後方，自動偵測：緊接「標籤文字)」（開頭無括號）或「(標籤文字)」／「（標籤文字）」，會自動拆出來填入該格的標籤欄位，標籤是「國際」時自動選灰色底、其餘一律紅色底。
- **照片編輯**：點擊、拖曳檔案，或先點選該格再用 Ctrl+V 貼上剪貼簿圖片即可上傳；直接在預覽圖上對著照片拖曳可調整位置，滑鼠停在該格上滾動滾輪、或用「圖片縮放」滑桿可放大縮小；「重設位置」可還原置中。單擊預覽圖上的任一格只會選取該格並自動捲動到對應的編輯區，雙擊該格才會開啟選擇檔案視窗。
- **每格欄位配置**：每一行標題文字／標籤文字的輸入框上方都是一列「欄位名稱＋顏色選取」（例如「第一行標題」＋色塊），顏色選取預設收合只顯示目前顏色的色塊，點一下展開完整選色列。
- **下載**：「下載本頁」「全部下載」並排在編輯區上方。預覽是 1040×800，但下載的檔案都會以 2 倍解析度（2080×1600）重新算圖匯出，並在檔案內嵌 300dpi 資訊（PNG 的 pHYs 區塊／JPG 的 JFIF 密度欄位），讓小字在放大檢視或列印時邊緣更乾淨、不容易因為 JPG 壓縮而糊在一起。
  - 下載本頁：目前分頁畫面上所有照片＋文字的完成品（JPG）。
  - 全部下載：一次把兩頁的完成品各存一張 JPG（部分瀏覽器第一次使用會詢問是否允許網站下載多個檔案，允許即可）。

## 使用方式

1. 開啟本頁（線上版或本機伺服器，見下方「本地開發」）。
2. 可直接展開「快速填入」貼上成批標題內容一次套用，或用預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換手動編輯。
3. 需要的話切換是否顯示頂部標籤列、修改標籤文字。
4. 依序為六格上傳照片、輸入兩行標題文字（顏色選取預設收合，點欄位名稱或色塊即可展開選色）與選填標籤。
5. 在預覽圖上拖曳/滾輪調整照片位置與縮放；單擊預覽圖上的格子會自動捲動到對應編輯區，雙擊該格則開啟選擇檔案視窗。
6. 按「下載本頁」取得單頁成品，或「全部下載」一次拿兩張。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部功能所在，純 HTML + CSS + 原生 JavaScript（Canvas 2D 繪圖），無外部相依套件 |
| `TaipeiSansTCBeta-Bold.ttf` | 標題套用的字型（台北黑體 Taipei Sans TC Beta Bold），以 `@font-face` 載入 |
| `assets/template-header.png` | 含頂部黃色標籤列的模板圖層，Canva 原始匯出檔，直接套用不重繪 |
| `assets/template-plain.png` | 不含標籤列（僅頂部淡淡暗角）的模板圖層，同樣是 Canva 原始匯出檔 |

## 技術說明

- 純前端實作，圖片合成、文字排版（含逐字距調整）皆透過 Canvas 2D API 即時繪製；版型的漸層／標籤列是直接 `drawImage` 疊上 `assets/` 底下的原始模板 PNG，不是用程式碼重繪近似圖形。
- 無框架、無建置流程。
- 下載功能使用 `canvas.toDataURL()` 產生檔案，全程在瀏覽器端完成，不會上傳任何圖片或文字內容到伺服器。

## 本地開發

因為版型會載入 `assets/` 底下的本機 PNG 圖檔疊到 canvas 上，瀏覽器基於安全限制，**直接雙擊開啟 `index.html`（`file://`）會導致下載失敗**（跳出提示訊息，canvas 被視為跨來源而無法匯出）。本機測試請先起一個簡單的 HTTP 伺服器再開啟，例如：

```
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```

部署後的網址（GitHub Pages 等正式 http/https 環境）不受此限制，可正常下載。
