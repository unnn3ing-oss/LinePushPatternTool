# Line推播套版產生器

**線上直接使用（GitHub Pages）：** https://unnn3ing-oss.github.io/LinePushPatternTool/

單一 HTML 檔案的小工具，固定「熱門話題」六宮格版型（頂部標籤列＋下方 3×2 共 6 格）。成品是**兩頁各自獨立**（預設第 1 頁含黃色標籤列、第 2 頁不含，僅頂部淡淡暗角），可分別更換每一頁每一格的照片、兩行標題文字與選填的小標籤（紅／灰底色可選），文字自動排版（字沒塞滿字框維持自然字距，太長才縮字距／字級），照片可拖曳調整位置、滾輪或滑桿縮放。預覽與下載檔案都是 1040×800，下載為無損 PNG 並內嵌 300dpi 資訊。

跟 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool) 是同一套操作邏輯（單一 HTML、Canvas 2D 即時預覽、拖曳/貼上上傳圖片），但版型固定為六宮格、成品分兩頁，並新增照片拖曳定位、縮放、標籤與自動字距／字級的功能。

## 功能特色

- **新聞／娛樂兩種版型**：畫面最上方切換。「新聞」為上述熱門話題六宮格（1040×800）；「娛樂」為拍立得四格（1200×1200，每格照片＋黃色字條上兩行標題＋藍色標籤，第一行預設藍字、第二行黑字），下載檔案為 1040×1040、300dpi PNG（以 3 倍算圖後精準縮小，維持清晰度）。兩種版型的資料各自保留、切換不會遺失，編輯、貼圖、快速填入（娛樂版一次填 8 格）共用。娛樂版標題字級依設計範例：基準 61px，字太長時先把字距壓緊（可到 -0.07em，讓字彼此貼近），仍放不下才縮字級，所以長句也維持接近原尺寸；標題並加 1px 同色描邊，粗細對齊範例（標籤文字不加粗）。同一列左右兩格的兩行標題與標籤高度一致。標籤為略斜的藍色撕邊膠帶造型，會依字數水平拉長。
- **拼圖**：第三個版型分頁，一張 1:1 畫布把多張照片無縫拼接。可「等分」（直向、橫向各不切～4 等分，在預覽圖上拖曳分隔線調整比例），或「自由框」（拖曳拉出矩形、移動、拉邊角改大小、磁吸貼齊、調整上下層、刪除，最多 12 框）。每框照片可拖曳、縮放、加T寶貼圖。「下載」為 1080×1080、300dpi PNG，檔名 `yyyymmdd拼圖.png`；「複製」會把成品放進剪貼簿，切到新聞或娛樂點選格子按 Ctrl+V 即可貼成該格照片（貼入非正方形格子時可再拖曳、縮放調整）。
- **兩頁各自獨立**：預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換編輯（頂部「新聞／娛樂／拼圖」與頁數的白色滑塊切換時會滑動過去，也可以用滑鼠按住滑塊左右拖曳，放開即切換），兩頁各有自己的 6 格內容（照片、文字、標籤、顏色）與「頂部標籤」（顯示黃色標籤列）開關，互不影響；切頁不會遺失另一頁的資料。
- **固定版型**：頂部標籤列（可切換顯示／隱藏、可改文字，預設「熱門話題」）＋下方 3×2 共 6 格，每格可獨立設定。背景／漸層直接套用實際輸出的模板 PNG 素材，確保跟原始設計完全一致。
- **選填標籤**：每格可加一個白字小標籤（例如「關鍵竟是房東」），底色可選紅色或灰色，顯示在該格標題文字正上方、靠左對齊。
- **第二段標籤（新聞版）**：每格可再加「標籤文字 2」（獨立的紅／灰底色），預設在該格右上角；快速填入可連寫兩個標籤（例如 `★（國際）（急集體隔離）標題 第二行`）：若其中恰有一個是「國際」或「獨家」，它會自動放在右上角（第二段）、另一個放在左下角（第一段）；若不是這種組合（兩個都不是、或兩個都是），則第一個放左下角、第二個放右上角；只寫一個標籤時維持放在左下角（第一段）。娛樂版只有一個標籤，取第一個。兩段標籤都能在預覽圖上直接拖曳，移動範圍限制在該格內、標題文字上方，並避開上方的黃色標籤列漸層與兩排之間的黑帶（第 1、2 頁各有各的上界，數值量自模板 PNG）；靠近格子邊緣會自動吸附貼齊，不顯示輔助線。「標籤位置還原」可把兩段標籤放回預設位置。娛樂版暫無第二段標籤。
- **文字自動排版**：每格兩行標題，兩行都可分別選顏色（白／黃／紅／藍／綠／黑），預設依欄位交錯白／黃配色。文字框左右完全貼齊格子邊線：字沒塞滿時維持自然字距置中，字距拉滿到貼邊仍放不下才開始壓縮字距，字距壓到 0（再壓會讓筆畫重疊）仍放不下才縮小 1 級字級，如此重複到能放進格子為止。
- **標點符號自動轉半形**：兩行標題、標籤文字、頂部標籤文字，以及「快速填入」貼入的內容，只要含有全形標點（！？（）＂＇，。、～等）或中文彎引號，都會自動轉成半形／直引號，不用自己切換輸入法。
- **快速填入**：預設展開（點標題可收起），可直接貼上整段過審的推播新聞（「★標題」＋下一行網址，網址會自動略過）；標題碰到空格（全形、半形）或「!」「?」就自動換到第二行（驚嘆號、問號留在第一行尾），依序自動套進第 1～12 格（第 1 頁 6 格接著第 2 頁 6 格，由左至右、由上至下），不用一格一格手動輸入。標籤文字支援兩種寫法，都寫在★後方，自動偵測：緊接「標籤文字)」（開頭無括號）或「(標籤文字)」／「（標籤文字）」，會自動拆出來填入該格的標籤欄位，標籤是「國際」時自動選灰色底、其餘一律紅色底。
- **快速填入自動抓文章首圖**：★ 標題下一行的文章連結，會自動抓該文章的第一張圖（og:image，沒有就取內文第一張）放進對應格子；之後想換圖，拖進新圖或 Ctrl+V 即可，手動放的圖再按快速填入也不會被蓋掉，抓不到的格子會在狀態列列出請手動放圖。瀏覽器不能直接讀其他網站內容，所以需要一個自架的 Cloudflare Worker 代理（只允許 tvbs.com.tw，程式碼與部署步驟見 [`worker/README.md`](worker/README.md)）；網頁以 `?imageProxy=<worker網址>` 開啟一次即記住設定（也可直接寫進 `DEFAULT_IMAGE_PROXY`），未設定時快速填入只填文字。
- **複製推播連結**：新聞／娛樂在「步驟 2 畫面檢查」點預覽圖的格子，該格整個會淡淡反灰（暗 10%，沒有藍框線），正中間會出現「複製推播連結」按鈕（編輯畫面時不顯示；點空白處或換頁會收起），只複製該格的**連結**（不含標題）。連結會先清掉文章編號之後的所有參數（舊的 utm 與其他參數全部刪除，只留文章網址），再加上對應的追蹤碼；連結來自快速填入時標題下一行的網址，沒有連結的格子會提示無法複製。範例：
  - 原始連結：`https://news.tvbs.com.tw/life/4030991`
  - 加上新聞推播追蹤碼：`https://news.tvbs.com.tw/life/4030991?utm_source=LineNewsPush&utm_medium=push`
  - 加上娛樂推播追蹤碼：`https://news.tvbs.com.tw/life/4030991?utm_source=LineNewsPush&utm_medium=enewsline`
- **照片編輯**：點擊、拖曳檔案，或先點選該格再用 Ctrl+V 貼上剪貼簿圖片即可上傳；直接在預覽圖上對著照片拖曳可調整位置，滑鼠停在該格上滾動滾輪、或用「圖片縮放」滑桿可放大縮小；「重設位置」可還原置中。照片放大後可再多拖出照片自身寬高各 7% 的邊界（露出白底），方便把邊緣的人物拉向中間。單擊預覽圖上的任一格只會選取該格並在左側浮出對應的編輯面板，雙擊該格才會開啟選擇檔案視窗。
- **T寶貼圖**：先在預覽圖點選要編輯的格子，點畫面底部浮動工具列「T寶貼圖」裡的其中一個表情貼圖即可加到該格正中央，用來蓋住照片中不想露出的人物（步驟 2 會鎖定，工具列上不顯示）。貼圖可在預覽圖上直接拖曳移動、滑鼠滾輪縮放，點貼圖右上角的「✕」即可移除；貼圖只存在於該格、該頁，切頁或清除本頁不影響其他頁。
- **操作提示彈窗**：網頁右下角的彈窗，依目前版型顯示快速上手要點——新聞（貼上就填好、點格子就能改、小標籤、照片與貼圖、檢查並下載）、娛樂（同樣流程，標籤為藍色膠帶）、拼圖（選版面、放照片、輸出）；開啟網頁時顯示，約 5 秒後自動收起成右下角的圓形「!」按鈕；游標移到彈窗上時會維持顯示，移出彈窗外 1 秒後漸漸收起；再按一次「!」可重新開啟，最下方的「詳細功能說明」會開啟完整說明。
- **詳細功能說明**：依目前介面撰寫，包含畫面怎麼看（最上方、預覽圖、左側浮動面板、底部工具列）、新聞／娛樂步驟 1 編輯畫面與步驟 2 畫面檢查（鎖定、檢查清單的綠色／黃色／紅色圓圈、疑似露白判斷、複製推播連結、下載規則）、拼圖做法、快速填入示範與輸出格式。
- **浮動面板編輯（點格子才出現）**：預覽圖固定在畫面正中間，編輯面板浮在預覽圖左側、緊貼預覽圖（相隔約 18px，視窗再寬也不會離很遠），頂端與預覽圖齊高。一開始左側是「快速填入」；新聞版點預覽圖上黃色的「熱門話題」標籤列，左側會浮出「頂部標籤」面板（取消勾選隱藏標籤列後，最上方「拼圖」右側會出現「頂部標籤」按鈕可再打開）；在預覽圖上點某一格，左側就換成那一格的編輯面板（新聞、娛樂、拼圖皆同），點畫面空白處或換頁則收起。按下「快速填入」後面板會自動收起，最上方「拼圖」右側會獨立出現「快速填入」按鈕可再打開。
- **每格欄位配置**：每一行標題文字／標籤文字的輸入框上方都是一列「欄位名稱＋顏色選取」（例如「第一行標題」＋色塊），顏色選取預設收合只顯示目前顏色的色塊，點一下展開完整選色列。
- **兩步驟流程（新聞、娛樂）**：畫面最上方有進度條「① 編輯畫面 → ② 畫面檢查」（不加底色，只有目前所在的步驟會顯示名稱，其餘只留圓圈數字，已完成的步驟打勾）。步驟 1 編輯內容（貼上快速填入、點格子改字／換圖、拖曳縮放、貼 T寶貼圖）；按底部「下一步：畫面檢查」進入步驟 2，**照片、標籤、貼圖全部鎖定**，拖曳時會跳出「套版已鎖定，回上一步才能調整」（旁有「返回上一步更改」按鈕）提醒（顯示 3 秒）。步驟 2 左側逐格列出檢查結果（綠色圓圈「圖」「字」＝沒問題，紅色圓圈「!」＝缺圖片／缺標題，黃色圓圈「!」＝疑似露白（照片被拖離格子，或照片自帶白邊／透明邊：只計算照片「看得到」的範圍——新聞版範本的黃色標籤列與陰影、頂端暗邊、底部黑色字條帶，以及上排字條帶多往下蓋進下排的部分，都會把照片遮住，遮住的地方露白不算；看得到的範圍內，把每格照片依輸出狀態畫出來，掃描四邊各 3px，任一邊有 90% 以上是近白色（RGB 皆 ≥ 240）或透明就標示；滑鼠停在圓圈上會顯示是哪一邊）；預覽圖上有問題的格子左上角也會標同樣的圓圈）：缺圖片、缺標題（沿用原本的完整度規則，會鎖住「全部下載」）以及圖片疑似露白（顯示黃色圓圈「!」，預覽圖上該格左上角也會標示；不鎖定下載，但按「下載本頁」「全部下載」時會跳提示「圖片有露白確定要下載嗎？」，可選擇仍要下載）；點預覽圖的格子，該格會淡淡反灰，正中間出現「複製推播連結」按鈕。**只有步驟 2 才有「下載本頁」「全部下載」**，要修改按底部「返回編輯」。拼圖沒有標題檢查，所以沒有進度條與步驟 2，底部直接是「下載」與「直接複製」。
- **檢查照片邊緣（步驟 1 的開關）**：步驟 1 底部工具列有「檢查照片邊緣」開關（預設關閉）。打開後預覽圖會用紅色框線把每格照片「看得到」的範圍整個框起來（新聞版的紅框與選取格子的藍框上下緣一致：上緣＝照片開始看得到的位置，下緣＝第一行標題上緣（小標籤下緣），娛樂版是相框洞的邊緣），純粹編輯時參考，其他區域不上色、也不做任何檢查或標示；只在螢幕上顯示，不會輸出到下載的圖片。露白的檢查與黃色「!」都在步驟 2 才進行（底部「N 格圖片疑似露白，仍可下載」也只在步驟 2 出現）。娛樂版的照片是從相框範本的洞露出來，被相框、膠帶、黃色字條遮住的部分不算露白（依範本逐像素判斷，傾斜的邊也準確）。
- **上排標題位置（新聞）**：上排兩行標題下移到離黑色字條帶下緣只剩 5px（第 1 頁黑邊下緣在 432px、第 2 頁在 414px；間距是 `TOP_ROW_TEXT_GAP` 常數），與下排字底離畫面底部的距離一致；左下角小標、藍色選取框、紅色「檢查照片邊緣」框與「複製推播連結」按鈕都跟著標題一起下移；上排照片下方的黑色漸層也往下滑，讓小標籤放上去後，漸層上緣與小標籤的相對位置和下排完全一樣（第 1 頁漸層上緣在小標籤上緣上方 16.8px、第 2 頁 19.8px；黑色底帶下緣不動，露白檢查的「看得到的範圍」同步更新）。
- **預覽區盡量放大（筆電小螢幕）**：預覽圖的大小改成依實際版面量測——從頁面籤下方量到底部工具列上方，與上方工具列、下方工具列各維持固定間距（下方 16px），在這個範圍內盡可能放大，方便編輯與拖曳；視窗高度 820px 以下時，底部工具列自動縮小（貼圖 40px、下緣 12px）多讓出一些高度。預覽圖大小仍不超過原本的上限（新聞 720px、娛樂與拼圖 620px），也不會多出頁面捲動。
- **試驗功能（第二套介面，開發中）**：網頁右上角「試驗功能」按鈕，點擊後輸入密碼才能進入（密碼由 Worker 驗證，網頁原始碼裡沒有，設定方式見 `worker/README.md`）；進入後標題旁出現橘色「試驗版」標記、頂端有橘色底線，再按一次回到標準介面（8 小時內再進入不用重新輸入）。推播標題只在「排入S8」視窗的「推播通知」欄位輸入（編輯畫面不再有「推播標題」卡片）。
- **試驗版「排入S8」**：試驗版步驟 2 的「全部下載」改為「排入S8」（同樣要先通過缺漏檢查與「已確認無錯字、圖片無露白？」確認）。按下後跳出視窗：群發名稱自動算好（`YYMMDD早／晚`，15:00 前為早、15:00 起為晚，例如 `261010晚`，可修改）、組織依版型自動選（新聞＝TVBS新聞、娛樂＝TVBS娛樂頭條）、平台 LINE、發送對象（全部 LINE 顧客，不加標籤條件）、推播通知（你在這個欄位輸入推播標題，例如「★我是推播標題 推播標題是我」，作為圖文訊息的 altText；新聞、娛樂各自記住最後輸入的內容）、兩則圖文訊息各 6（娛樂 4）個項目連結與依版面算好的點擊區塊座標（imagemap）。**注意：S8 的建立群發工具沒有「群發名稱」欄位**，建立後請到 Console 貼上剛剛複製的名稱手動命名。（S8 分頁的視窗標題現在是「排入推播」。）
- **試驗版「排入推播」（左上切換：LINE原生推播／S8推播）**：第二步驟（畫面檢查）底部的按鈕是「下載本頁｜全部下載｜排入LINE推播」（開啟試驗功能才有第三顆）；點「排入LINE推播」開啟彈窗，彈窗左上可切換「LINE原生推播」（預設）與「S8推播」（游標移到 S8 會提示「功能受限每月MCP上限」，S8 的原有步驟都在這個分頁）。LINE原生推播不經過 S8、不吃 S8 額度，樣式與 S8 的步驟完全一致：① 傳送資料（上傳與 S8 同一張 1040 圖，請 LINE 檢查格式，不發送）→ ② 選擇發佈方式（「立即推播」；「排程推播」目前沒有，因為 LINE 的 API 只能立即發送）→ ③ 推播測試帳號（狀態正常、到手機確認後按「測試完成」才進下一步）→ ④ 正式推播（綠色「正式推播」→ 黃色「確定推播？」→ 像 iPhone 滑動關機的開關，滑到右側才真的推播，結果顯示在下方狀態窗，失敗也是）。**沒有草稿、沒有排程，推播出去就收不回**。正式帳號另需 Worker 設 `LINE_ALLOW_OFFICIAL=1`，並且同一份內容先成功推播過測試帳號；好友數由 Worker 向 LINE 查詢並比對。折疊區「帳號與額度、發送紀錄與點擊次數」可查帳號額度，並用發送時的 request id 查每個連結的點擊次數與人數（只保留 14 天、不足 20 顯示「—」），可複製成表格。設定方式與安全規則見 [worker/README.md](worker/README.md) 的「LINE 官方帳號直接發送」。
- **試驗版「連結 S8」（OAuth）**：試驗版右上角有「S8 未連結／已連結」按鈕。彈窗由上而下是：連結狀態、提示窗，再來是按鈕「連結 S8」「中斷連結」（會先跳警告確認才中斷）「檢查連結狀態」（「查看工具定義」功能保留，暫時隱藏）。連結時**一次授予讀取＋寫入權限**（`insightark-mcp:read insightark-mcp:write`），並記住帶 write 的用戶端 id 以避免反覆授權；憑證由 Worker 代管（網頁只拿到看不懂的加密字串）。「排入S8」視窗內另有「計算符合條件的客戶數」（唯讀試算，組織只能是 TVBS新聞／TVBS娛樂頭條、參數固定為 LINE 且不加任何條件）。設定細節見 `worker/README.md`。
- **試驗版「直接建立」（階段三）**：連結好 S8 後，在「排入S8」視窗：上半部是**連結預覽**（上方切「第 1 頁／第 2 頁」，點圖上的格子，下方字框顯示並可修改該格的完整連結；每格的區塊名稱用快速填入的標題「★標題一 標題二」）；下方「傳送資料給S8」依五個步驟進行，上方有**水平步驟列**（① ── ② ── ③ ── ④ ── ⑤，目前這步顯示名稱，完成的變綠；點已走到的圓圈可回到那一步重來）。控制項是灰色底框＋白色有陰影的按鈕，**同寬同高**，完成上一步才出現下一步，且只留「剛完成」和「目前這一步」兩個：**① 傳送資料**（Worker 把兩張圖上傳到 S8 並試算可發送人數；按之前灰框貼齊按鈕，有狀態才往右彈開顯示：傳送中／傳送完成與人數／失敗原因）→ **② 存成草稿／設定排程**（二選一，選中的轉藍色；「設定排程」內是**日期選擇器**（顯示 MM/DD，預設今天）和**時間選擇器**（顯示 HH:MM，預設現在 +3 小時））→ **③ 確認人數**（數字框內提示正確人數，打錯 ✗ 紅、打對 ✓ 綠）→ **④ 複製群發名稱**（按下短暫顯示「已複製名稱」，之後保留綠色圓形打勾）→ **⑤ 建立草稿／建立排程**。按鈕顏色：還沒動作＝白；選擇型按了＝藍；有狀態回饋的成功＝綠、失敗或填錯＝紅；傳送中＝米黃；建立中＝淺藍；建立失敗＝黃並在下方彈出問題說明。建立成功會跳彈窗提醒到 S8 後台確認，並貼上剛剛複製的名稱為群發命名（S8 的建立工具沒有名稱欄位）。**新聞、娛樂各自獨立保留進度**（步驟、傳送結果、選擇、排程時間、確認人數、名稱、預覽圖；切換版型或關掉視窗再開都還在；畫面內容改過或建立完成後再開則重新開始；建立中不能關視窗）。發送對象固定為全部 LINE 顧客（不加條件），**不會立即發送**，程式裡不存在 resume／立即發送的路徑。兩種處理方式：
  - **存成草稿**：Worker 先以「建立當下 + 24 小時」排程，隨即暫停成草稿並再次確認狀態，不會發送。若暫停沒成功，畫面會用紅字寫出 taskId 與它排定的發送時間，並提供「重試暫停成草稿」，同時請你立即到 S8 Console 處理。
  - **設定排程**（需要明確選擇）：**不暫停**，這筆群發會在你選的時間（台北時間，到分鐘）**實際發送**給全部 LINE 顧客。時間範圍由 Worker 強制：**建立當下 +30 分鐘 ～ +7 天**，太近、過去、超過 7 天或不存在的日期都被拒絕；仍須輸入人數才能建立；步驟 5 的按鈕與確認視窗都會寫出「將在 YYYY-MM-DD HH:mm 實際發送給 N 人」。成功後以**紅字橫幅**顯示確切發送時間、taskId 與 S8 回報的狀態，並提供「暫停成草稿」按鈕（走 `/s8/pause`）；關閉視窗時若還有未暫停的排程會先提醒。

  S8 的建立工具沒有群發名稱欄位，建立後請到 Console 改名。原本「複製指令給 Claude」的流程仍可使用。
- **操作提示的設計語彙**：右下角「操作提示」彈窗與「!」圓鈕改成和左側浮動面板同一套白色風格（白色大圓角卡片、圓形關閉鈕、圓形圖示、藍色膠囊形「詳細功能說明」按鈕；「!」圓鈕為白底藍字），位置維持在畫面右下角；「詳細功能說明」視窗同步改成大圓角、圓形關閉鈕、藍色圓圈步驟編號，確認視窗與下載確認氣泡的按鈕也都是膠囊形。
- **「!」說明彈窗**：步驟 2，滑鼠移到預覽圖某格左上角的「!」上，會跳出說明該格被標示的原因（例如「照片被拖離格子，邊緣露出空白」、「照片左、右邊疑似白邊或透明」、紅色「!」則說明缺圖片／缺標題）；滑鼠移開後等 1 秒再漸漸淡出。
- **下載**：下載按鈕在畫面底部的浮動工具列（新聞、娛樂在步驟 2）。下載檔案為**無損 PNG**，**尺寸固定**（新聞 1040×800、娛樂 1040×1040、拼圖 1080 寬），並內嵌 300dpi 資訊（PNG 的 pHYs 區塊）。為了在固定尺寸下讓畫面更清晰，匯出時先以 3 倍大小繪製（照片直接從原圖一次縮放、文字與邊緣每個像素取 9 個取樣點），再精準平均縮回固定尺寸，文字與線條邊緣比直接 1:1 繪製更平滑；PNG 沒有 JPG 的壓縮雜訊。**檔案大小必須小於 2MB（推播平台限制）**：若無損 PNG 超過上限，會自動把色階依序微調（每色 2、4、8、16 階）直到小於 2MB，尺寸不變，並在下載後提示；若連最粗的調整仍超過，會提示換掉細節很多的照片。檔名格式為「下載當天日期＋版型＋Line推播圖_第幾頁」，例如 `20260925新聞Line推播圖_第1頁.png`。按「全部下載」時，按鈕上方會先跳出確認「已確認無錯字、圖片無露白？」，選「確認下載」才會下載，「再修改」或點別處可取消。
  - 下載本頁：目前分頁畫面上所有照片＋文字的完成品（PNG）。
  - 全部下載：一次把兩頁的完成品各存一張 PNG（部分瀏覽器第一次使用會詢問是否允許網站下載多個檔案，允許即可）。

## 使用方式

1. 開啟本頁（線上版或本機伺服器，見下方「本地開發」）。
2. 在左側「快速填入」貼上成批標題內容一次套用，或用預覽圖上方「第 1 頁」「第 2 頁」分頁籤切換、點格子手動編輯。
3. 新聞版需要的話，點預覽圖上黃色的「熱門話題」標籤列，在左側浮出的面板切換是否顯示標籤列、修改標籤文字。
4. 依序為六格上傳照片、輸入兩行標題文字（顏色選取預設收合，點欄位名稱或色塊即可展開選色）與選填標籤。
5. 在預覽圖上拖曳/滾輪調整照片位置與縮放；單擊預覽圖上的格子會在左側浮出對應編輯面板，雙擊該格則開啟選擇檔案視窗。
6. 按底部「下一步：畫面檢查」核對缺圖、缺標題、露白，確認後按「下載本頁」取得單頁成品，或「全部下載」一次拿兩張（拼圖沒有這一步，直接按底部「下載」）。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部功能所在，純 HTML + CSS + 原生 JavaScript（Canvas 2D 繪圖），無外部相依套件 |
| `TaipeiSansTCBeta-Bold.woff2` | 標題套用的字型（台北黑體 Taipei Sans TC Beta Bold）的 WOFF2 壓縮版，瀏覽器優先載入這個（比 .ttf 小約 65%，字元涵蓋範圍完全相同） |
| `TaipeiSansTCBeta-Bold.ttf` | 同一套字型的原始 TTF，僅作為不支援 WOFF2 的舊瀏覽器備援，一般瀏覽器不會下載到這個檔案 |
| `assets/template-header.png` | 含頂部黃色標籤列的模板圖層，Canva 原始匯出檔，直接套用不重繪 |
| `assets/template-plain.png` | 不含標籤列（僅頂部淡淡暗角）的模板圖層，同樣是 Canva 原始匯出檔 |
| `worker/og-image-proxy.js` | Cloudflare Worker：快速填入抓文章首圖用的小代理（需自行部署，說明見 `worker/README.md`） |
| `assets/template-ent.png` | 娛樂版拍立得四格模板（1200×1200，照片框為透明），由設計稿還原；拿到設計原檔後直接以同檔名覆蓋即可 |
| `assets/stickers/*.png` | 可疊加在照片上、用來遮擋人物的 T 寶表情貼圖（透明背景 PNG） |
| `assets/icons/*` | 網頁分頁圖示（favicon），喇叭圖案，呼應版型本身的黃色標籤列圖示 |

## 技術說明

- 純前端實作，圖片合成、文字排版（含逐字距調整）皆透過 Canvas 2D API 即時繪製；版型的漸層／標籤列是直接 `drawImage` 疊上 `assets/` 底下的原始模板 PNG，不是用程式碼重繪近似圖形。
- 無框架、無建置流程。
- 下載功能使用 `canvas.toDataURL()` 產生檔案，全程在瀏覽器端完成，不會上傳任何圖片或文字內容到伺服器。

## 本地開發

因為版型會載入 `assets/` 底下的本機 PNG 圖檔疊到 canvas 上，瀏覽器基於安全限制，**直接雙擊開啟 `index.html`（`file://`）會導致下載失敗**（跳出提示訊息，canvas 被視為跨來源而無法匯出）。本機測試請先起一個簡單的 HTTP 伺服器再開啟，例如：

```
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```

部署後的網址（GitHub Pages 等正式 http/https 環境）不受此限制，可正常下載。
