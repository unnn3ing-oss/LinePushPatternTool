# 熱門話題套版產生器

**線上直接使用（GitHub Pages）：** https://unnn3ing-oss.github.io/LinePushPatternTool/

單一 HTML 檔案的小工具，固定「熱門話題」六宮格版型（頂部標籤列＋下方 3×2 共 6 格）。成品是**兩頁各自獨立**（預設第 1 頁含黃色標籤列、第 2 頁不含，僅頂部淡淡暗角），可分別更換每一頁每一格的照片、兩行標題文字與選填的紅底小標籤，文字自動排版（先調字距、字距縮到最緊仍放不下才縮字級），照片可拖曳調整位置、滾輪或滑桿縮放。每頁輸出尺寸固定 1040×800。

跟 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool) 是同一套操作邏輯（單一 HTML、Canvas 2D 即時預覽、拖曳/貼上上傳圖片），但版型固定為六宮格、成品分兩頁，並新增照片拖曳定位、縮放、標籤與自動字距／字級的功能。

## 功能特色

- **兩頁各自獨立**：左上角「第 1 頁」「第 2 頁」分頁籤切換編輯，兩頁各有自己的 6 格內容（照片、文字、標籤、顏色）與「顯示頂部黃色標籤列」開關，互不影響；切頁不會遺失另一頁的資料。
- **固定版型**：頂部標籤列（可切換顯示／隱藏、可改文字，預設「熱門話題」）＋下方 3×2 共 6 格，每格可獨立設定。背景／漸層直接套用實際輸出的模板 PNG 素材，確保跟原始設計完全一致。
- **選填標籤**：每格可加一個紅底白字小標籤（例如「關鍵竟是房東」），顯示在該格標題文字正上方、靠左對齊。
- **文字自動排版**：每格兩行標題，兩行都可分別選顏色（白／黃／紅／藍／綠／黑），預設依欄位交錯白／黃配色。每一行的字距、字級各自獨立計算：先用字距把文字平均撐滿字框寬度，撐不下時改壓縮字距，字距壓到最緊仍放不下才縮小字級，確保不超出格子。
- **照片編輯**：點擊、拖曳檔案，或先點選該格再用 Ctrl+V 貼上剪貼簿圖片即可上傳；直接在預覽圖上對著照片拖曳可調整位置，滑鼠停在該格上滾動滾輪、或用左側「縮放」滑桿可放大縮小；「重設位置」可還原置中。
- **下載**：
  - 下載本頁完成圖（JPG）：目前分頁畫面上所有照片＋文字的完成品，1040×800。
  - 下載本頁空白模板（PNG）：只輸出目前分頁選擇的版型（含或不含頂部標籤列）的深色漸層／版面結構，照片區塊透明、不含文字，方便另外用其他軟體疊圖。
  - 下載兩頁完成圖（2 張 JPG）：一次把兩頁的完成品各存一張（部分瀏覽器第一次使用會詢問是否允許網站下載多個檔案，允許即可）。

## 使用方式

1. 開啟本頁（線上版或本機伺服器，見下方「本地開發」）。
2. 用「第 1 頁」「第 2 頁」分頁籤切換要編輯的頁面。
3. 需要的話切換是否顯示頂部標籤列、修改標籤文字。
4. 依序為六格上傳照片、輸入標籤（選填）與兩行標題文字、選各行顏色。
5. 在預覽圖上拖曳/滾輪調整照片位置與縮放。
6. 按「下載本頁完成圖（JPG）」取得單頁成品，或「下載兩頁完成圖」一次拿兩張；「下載本頁空白模板（PNG）」可取得空白版型。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部功能所在，純 HTML + CSS + 原生 JavaScript（Canvas 2D 繪圖），無外部相依套件 |
| `whz-heavy.ttf` | 標題套用的字型（WHZ-Heavy），以 `@font-face` 載入 |
| `assets/template-header.png` | 含頂部黃色標籤列的模板圖層，Canva 原始匯出檔，直接套用不重繪 |
| `assets/template-plain.png` | 不含標籤列（僅頂部淡淡暗角）的模板圖層，同樣是 Canva 原始匯出檔 |

## 技術說明

- 純前端實作，圖片合成、文字排版（含逐字距調整）皆透過 Canvas 2D API 即時繪製；版型的漸層／標籤列是直接 `drawImage` 疊上 `assets/` 底下的原始模板 PNG，不是用程式碼重繪近似圖形。
- 無框架、無建置流程。
- 下載功能使用 `canvas.toDataURL()` 產生檔案，全程在瀏覽器端完成，不會上傳任何圖片或文字內容到伺服器。

## 本地開發

因為版型會載入 `assets/` 底下的本機 PNG 圖檔疊到 canvas 上，瀏覽器基於安全限制，**直接雙擊開啟 `index.html`（`file://`）會導致「下載完成圖／空白模板」失敗**（跳出提示訊息，canvas 被視為跨來源而無法匯出）。本機測試請先起一個簡單的 HTTP 伺服器再開啟，例如：

```
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```

部署後的網址（GitHub Pages 等正式 http/https 環境）不受此限制，可正常下載。
