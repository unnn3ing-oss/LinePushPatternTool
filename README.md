# 熱門話題套版產生器

**線上直接使用（GitHub Pages）：** https://unnn3ing-oss.github.io/LinePushPatternTool/

單一 HTML 檔案的小工具，固定「熱門話題」六宮格版型（頂部黃色標籤列＋下方 3×2 共 6 格），可分別更換每一格的照片與兩行標題文字，文字自動調整字距（字距縮到最緊仍放不下才會縮小字級），照片可拖曳調整位置、滾輪或滑桿縮放。輸出尺寸固定 1040×800。不需安裝、不需建置，開啟 `index.html` 即可使用。

跟 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool) 是同一套操作邏輯（單一 HTML、Canvas 2D 即時預覽、拖曳/貼上上傳圖片），但版型固定為六宮格，並新增照片拖曳定位、縮放與自動字距／字級的功能。

## 功能特色

- **固定版型**：頂部黃色標籤列（可改文字，預設「熱門話題」）＋下方 3×2 共 6 格，每格可獨立設定。
- **文字自動排版**：每格兩行標題，第一行固定白色、第二行可選強調色（紅／黃／藍／綠／白／黑）。文字太長時，會先自動縮小字距；字距已經縮到最緊仍放不下，才會縮小字級，確保不超出格子。
- **照片編輯**：點擊、拖曳檔案，或先點選該格再用 Ctrl+V 貼上剪貼簿圖片即可上傳；直接在預覽圖上對著照片拖曳可調整位置，滑鼠停在該格上滾動滾輪、或用左側「縮放」滑桿可放大縮小；「重設位置」可還原置中。
- **兩種輸出**：
  - 下載完成圖（JPG）：目前畫面上所有照片＋文字的完成品，1040×800。
  - 下載空白模板（PNG）：只輸出頂部標籤與六格的深色漸層／版面結構，照片區塊透明、不含文字，方便另外用其他軟體疊圖。

## 使用方式

1. 開啟 `index.html`（任何現代瀏覽器）。
2. 需要的話修改頂部標籤文字。
3. 依序為六格上傳照片、輸入兩行標題文字、選第二行強調色。
4. 在預覽圖上拖曳/滾輪調整照片位置與縮放。
5. 按「下載完成圖（JPG）」取得成品，或按「下載空白模板（PNG）」取得空白版型。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部功能所在，純 HTML + CSS + 原生 JavaScript（Canvas 2D 繪圖），無外部相依套件 |
| `whz-heavy.ttf` | 標題套用的字型（WHZ-Heavy），以 `@font-face` 載入 |

## 技術說明

- 純前端實作，圖片合成、文字排版（含逐字距調整）皆透過 Canvas 2D API 即時繪製。
- 無框架、無建置流程，任何現代瀏覽器直接開啟 `index.html` 即可執行。
- 下載功能使用 `canvas.toDataURL()` 產生檔案，全程在瀏覽器端完成，不會上傳任何圖片或文字內容到伺服器。

## 本地開發

直接用瀏覽器開啟 `index.html` 即可，修改後重新整理頁面查看結果，不需額外安裝依賴或啟動伺服器。
